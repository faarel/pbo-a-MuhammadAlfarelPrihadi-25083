## Tujuan Praktikum
Praktikum ini bertujuan memahami penggunaan class dan constructor dalam pemrograman berorientasi objek menggunakan Java dan PHP.

## Penjelasan Program
Pada praktikum ini dibuat class `Mahasiswa` untuk merepresentasikan data mahasiswa. Class digunakan sebagai cetak biru objek, sedangkan constructor dijalankan ketika objek dibuat dan dapat digunakan untuk memberikan nilai awal pada atribut. File `Main` digunakan untuk membuat objek dan menampilkan data yang sudah diberikan.

Program dibuat dalam dua bahasa, yaitu Java dan PHP, agar terlihat bahwa konsep class dan constructor dapat diterapkan pada bahasa pemrograman yang berbeda.
