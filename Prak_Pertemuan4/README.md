## Tujuan Praktikum
Memahami pewarisan sifat antarclass (*inheritance*) dan penggunaan method yang dapat memberikan perilaku berbeda melalui *polymorphism*.

## Penjelasan Program
Program menggunakan class induk `Pegawai` dan class turunan `PegawaiTetap` serta `PegawaiKontrak`. Class induk menyimpan bagian yang umum dimiliki pegawai, sedangkan class turunan dapat memiliki data atau perhitungan sesuai jenis pegawainya. File `Main.java` dan `main.php` digunakan untuk membuat objek dan menjalankan program.

Inheritance membantu mengurangi penulisan kode berulang karena class turunan dapat menggunakan anggota dari class induk. Polymorphism memungkinkan method yang sama dipanggil dengan hasil atau perilaku yang berbeda sesuai objek yang digunakan.

## Kesimpulan
Praktikum ini menunjukkan bahwa inheritance memudahkan penggunaan kembali kode dari class induk, sedangkan polymorphism membuat program lebih fleksibel karena implementasi method dapat disesuaikan dengan jenis objek.
