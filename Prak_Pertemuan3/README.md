## Tujuan Praktikum
Memahami pengelolaan data melalui class serta penerapan konsep enkapsulasi pada program Java dan PHP.

## Penjelasan Program
Program menggunakan class `RekeningBank` untuk merepresentasikan rekening bank. Data dan operasi yang berhubungan dengan rekening dikelola melalui class agar penggunaannya lebih terstruktur. Folder Java dan PHP berisi implementasi konsep yang serupa pada masing-masing bahasa. File `main` digunakan untuk membuat objek dan menjalankan operasi program.

Enkapsulasi membantu menjaga pengelolaan data agar dilakukan melalui bagian class yang memang disediakan, bukan dengan mengakses data secara sembarangan.
